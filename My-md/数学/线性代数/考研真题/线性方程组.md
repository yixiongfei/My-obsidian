## 1.
![[Pasted image 20260816204841.png]]

> [!question]- 💡 提示 1：把"同解"翻译成一句能直接代入的话
> "$Ax=0$ 与 $Bx=0$ 同解"，本质就是**两个方程组的解集是同一个集合**——记这个公共解集为 $S$（也就是 $\operatorname{null}(A)=\operatorname{null}(B)=S$）。凡是看到"同解"，第一反应就该把它翻译成这句话，而不是去算具体的 $A,B$。

> [!question]- 💡 提示 2：分块方程组怎么拆
> $y=\binom{x_1}{x_2}$，把选项里的分块矩阵乘出来，你会发现每个分块方程组其实是**两个方程叠在一起**（比如 C 选项第一个方程组：$Ax_1+Bx_2=0$ 且 $Bx_2=0$）。先看"只含一个未知量"的那个方程（通常在下面一行），能直接判断这个未知量在不在 $S$ 里，再代回另一个方程化简。

> [!question]- 💡 提示 3：C 选项的两个方程组分别化简成什么
> 用提示 2 的方法把 C 的两个分块方程组都化简一遍，你会发现它们最后都化简成了同一个条件：$x_1\in S$ 且 $x_2\in S$。这说明了什么？
>
> 再试试用同样方法拆 D 选项——拆到最后，两个方程组里 $x_1$ 满足的条件真的一样吗？（提示：一个是 $Bx_1\in S$，一个是 $Ax_1\in S$，这两个条件对任意满足题设的 $A,B$ 都相等吗？）

> [!success]- ✅ 答案与完整推导
> **核心翻译**：设 $S=\operatorname{null}(A)=\operatorname{null}(B)$（公共解集）。
>
> **C 选项化简**：
> $\begin{pmatrix}A&B\\O&B\end{pmatrix}y=0$：即 $Ax_1+Bx_2=0$ 且 $Bx_2=0$。由第二式 $x_2\in S$；代回第一式，$Bx_2=0$ 已知，所以 $Ax_1=0$，即 $x_1\in S$。**解集为 $x_1\in S,\ x_2\in S$。**
>
> $\begin{pmatrix}B&A\\O&A\end{pmatrix}y=0$：即 $Bx_1+Ax_2=0$ 且 $Ax_2=0$。同理得 $x_2\in S$，代回得 $Bx_1=0$，即 $x_1\in S$。**解集同样是 $x_1\in S,\ x_2\in S$。**
>
> 两个方程组解集完全相同（都是 $S\times S$），**C 正确**。
>
> **D 选项为什么不对（反例）**：
> D 化简后条件变成"$Bx_1\in S$"（第一个方程组）vs"$Ax_1\in S$"（第二个方程组）——这不再是简单的"$x_1\in S$"，而是要看 $A,B$ 把 $S$ 以外的向量"压缩"成什么样，两者不保证相等。
>
> 取 $n=2$，$S=\operatorname{span}\{(1,0)^T\}$，$A=\begin{pmatrix}0&1\\0&0\end{pmatrix}$，$B=\begin{pmatrix}0&1\\0&1\end{pmatrix}$（验证：$\operatorname{null}(A)=\operatorname{null}(B)=S$，满足题设）。
> - $D$ 第一个方程组解集化简为 $x_1\in S,\ x_2\in S$（2 维）
> - $D$ 第二个方程组解集化简为 $x_1\in\mathbb{R}^2$（任意）、$x_2\in S$（3 维）
>
> 两者维数都不一样，**明显不同解，D 不成立**。
>
> **A、B 选项为什么不对（反例）**：取 $A=B=O$（零矩阵），显然 $Ax=0$ 与 $Bx=0$ 同解（两者解集都是全空间）。代入 A 选项 $\begin{pmatrix}O&O\\E&O\end{pmatrix}y=0$，化简得 $x_1=0$、$x_2$ 任意——**不是只有零解**，A 不成立。B 选项同理，取 $A=B=O$ 代入 $\begin{pmatrix}E&O\\O&O\end{pmatrix}$-型方程也会得到非零解，B 不成立。
>
> **选 C。**

## 📐 "同解"的核心性质

**定义（本质）**：$Ax=0$ 与 $Bx=0$ 同解 $\iff \operatorname{null}(A)=\operatorname{null}(B)$（两者解集作为集合相等）。做题时把"同解"第一时间翻译成"公共解集 $S$"，比死磕矩阵运算好用得多。

**标准判定定理（比定义更常用，证明题首选）**：
$$Ax=0 \text{ 与 } Bx=0 \text{ 同解} \iff r(A)=r(B)=r\binom{A}{B}$$
其中 $\binom{A}{B}$ 是把 $A,B$ 按行拼接成的大矩阵。直觉：如果同解，合起来的方程组 $\binom{A}{B}x=0$ 并不会比单独的 $Ax=0$ 多任何约束，秩自然不变。

**同解 vs 初等变换（与"行变换不改变方程组"的呼应）**：
- $P$ 可逆 $\Rightarrow Ax=0$ 与 $(PA)x=0$ **同解**（左乘可逆矩阵 = 行变换，不改变解集，这是"同解"最基础的来源）
- 右乘可逆矩阵（列变换）**不保证同解**——这正是 [[矩阵的运算与变换]] 里"2."那道题选项 D 出错的原因，两者是同一个知识点的两个角度。

**适用场景**：分块方程组、证明两个方程组同解、由同解条件反推矩阵的秩或结构，都可以先把"同解"翻译成"公共零空间 $S$"，再逐个方程代入化简。

## 📐 常用套路：判断两个向量组是否等价，先查秩

**核心必要条件**：
$$\text{向量组 } \alpha \text{ 与 } \beta \text{ 等价} \Rightarrow r(\alpha)=r(\beta)$$
（等价 = 张成同一个空间 = 维数相同，秩不等直接排除）

**含公共向量时的简化技巧**：如果两组向量共享若干个向量（比如都含 $\alpha_1,\alpha_2$），只需要关注"剩下不同的那个向量加进来之后，秩会不会变"——把两组各自拼成方阵，比较行列式是否为 0，比逐个讨论线性表示快得多。

**易错点**：像本题这种两个行列式**因式有公共零点**（都在 $\lambda=1$ 处为 0）的情况，公共零点处不能直接归为"排除"，必须单独代入验证——本题 $\lambda=1$ 反而是保留的，是最容易漏看/搞反的一步。

**适用场景**：含参数的向量组等价问题、判断向量组等价的取值范围，都可以先用这套"拼方阵 + 查行列式"的方法快速定位可疑点，再对边界值单独验证。

## 📐 线性方程组解的性质与几何意义

### 一、齐次线性方程组 $Ax=0$

**解的性质（解集对线性运算封闭）**：
- $\xi_1,\xi_2$ 是解 $\Rightarrow \xi_1+\xi_2$ 也是解：$A(\xi_1+\xi_2)=A\xi_1+A\xi_2=0+0=0$
- $\xi$ 是解，$k$ 为任意数 $\Rightarrow k\xi$ 也是解：$A(k\xi)=kA\xi=0$
- 两条合起来：**解集是一个向量空间**（叫**解空间**），因为对加法、数乘都封闭

**解的结构（基础解系 + 通解）**：
$$\dim(\text{解空间})=n-r(A)\quad(n=\text{未知数个数})$$
$$x=k_1\xi_1+k_2\xi_2+\cdots+k_{n-r}\xi_{n-r}\qquad(\xi_i\text{ 为基础解系，}k_i\text{ 任意})$$

**几何意义**：解集是 $\mathbb{R}^n$ 中**过原点**的 $(n-r)$ 维子空间（$x=0$ 永远是解）。
- $n=3,r=1$：==过原点的**平面**==
- $n=3,r=2$：==过原点的**直线**==
- $n=3,r=3$：==**只有原点**（只有零解）==

### 二、非齐次线性方程组 $Ax=b$（$b\neq0$）

**解的性质（解集不再封闭，但和"导出组" $Ax=0$ 有固定关系）**：
- $\eta_1,\eta_2$ 是 $Ax=b$ 的解 $\Rightarrow \eta_1-\eta_2$ 是**导出组** $Ax=0$ 的解（不再是 $Ax=b$ 的解）：$A(\eta_1-\eta_2)=b-b=0$
- $\eta$ 是 $Ax=b$ 的解，$\xi$ 是导出组 $Ax=0$ 的解 $\Rightarrow \eta+\xi$ 仍是 $Ax=b$ 的解：$A(\eta+\xi)=b+0=b$
- **解集不是向量空间**：两个解相加不再是解，也不含零向量（除非 $b=0$）——这是和齐次方程组最本质的区别

**解的结构（通解 = 特解 + 导出组通解）**：
$$x=\eta_0+k_1\xi_1+\cdots+k_{n-r}\xi_{n-r}$$
$\eta_0$ 是 $Ax=b$ 的**任意一个特解**，$\xi_1,\ldots,\xi_{n-r}$ 是导出组 $Ax=0$ 的基础解系。

**几何意义**：解集是 $\mathbb{R}^n$ 中**不过原点**的 $(n-r)$ 维"平面"——把导出组的解空间（过原点的子空间）**沿 $\eta_0$ 方向整体平移**得到的（专业说法叫**仿射子空间**）。
- $n=3,r=2$：导出组解空间是过原点的直线，$Ax=b$ 的解集是一条**平行于它、但不过原点**的直线
- $n=3,r=1$：导出组解空间是过原点的平面，$Ax=b$ 的解集是**平行于它、但不过原点**的平面

### 三、解的存在性 / 个数判定（配合使用）

$$Ax=b \text{ 有解} \iff r(A)=r(A,b)\ (\text{系数矩阵秩 = 增广矩阵秩})$$

| 条件 | 解的个数 |
|---|---|
| $r(A)\neq r(A,b)$ | 无解 |
| $r(A)=r(A,b)=n$ | 唯一解 |
| $r(A)=r(A,b)<n$ | 无穷多解（差 $n-r$ 维） |

齐次方程组 $Ax=0$ 永远有解（$x=0$），只需判断 $r(A)=n$（只有零解）还是 $r(A)<n$（有非零解）。

### 四、对比表 + 核心联系

| | 齐次 $Ax=0$ | 非齐次 $Ax=b$（$b\neq0$） |
|---|---|---|
| 解集结构 | 向量空间（子空间） | 仿射空间（子空间的平移） |
| 含零向量 | 恒含 | 不含 |
| 加法/数乘封闭 | 是 | 否 |
| 几何图像 | 过原点的直线/平面/超平面 | 不过原点、平行于导出组解空间的直线/平面 |

**核心联系一句话**：非齐次方程组的解集 = "一个特解" + "导出组的解空间"，几何上就是把一个过原点的子空间**整体平移**到经过 $\eta_0$ 的位置——这也是通解公式 $x=\eta_0+k_1\xi_1+\cdots$ 长这个样子的根本原因。
