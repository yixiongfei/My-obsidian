# 有理函数不定积分解法

## 1. 拆分规则 (待定系数法)

| 分母因式类别 | 分式形式 | 拆分目标 | 积分方向 |
| :--- | :--- | :--- | :--- |
| **单项一次** | $\frac{1}{x-a}$ | $\frac{A}{x-a}$ | $\to \ln\|x-a\|$ |
| **重复一次** | $\frac{1}{(x-a)^k}$ | $\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \dots + \frac{A_k}{(x-a)^k}$ | $\to \text{幂函数} / \ln$ |
| **不可约二次** $(\Delta < 0)$ | $\frac{1}{x^2+px+q}$ | $\frac{Ax+B}{x^2+px+q}$ | $\to \ln + \arctan$ |

---

## 2. 不可约二次项解法 ($\frac{Ax+B}{x^2+px+q}$)

核心思路：**分子凑导数 ($\ln$) + 余项配方 ($\arctan$)**

$$\frac{Ax+B}{x^2+px+q} \xrightarrow{\text{凑微分}} \frac{A}{2} \cdot \frac{2x+p}{x^2+px+q} + \frac{B - \frac{Ap}{2}}{(x+\frac{p}{2})^2 + (q - \frac{p^2}{4})}$$

* **前项**：$\int \frac{2x+p}{x^2+px+q} dx = \ln(x^2+px+q)$
* **后项**：$\int \frac{1}{u^2+a^2} du = \frac{1}{a}\arctan\left(\frac{u}{a}\right)$

## 3. 典型例题

### 例 1：$\int \frac{1}{(x+1)(x^2-2x+2)} dx$

**Step 1. 拆分**
$$\frac{1}{(x+1)(x^2-2x+2)} = \frac{A}{x+1} + \frac{Bx+C}{x^2-2x+2}$$
$$\implies A=\frac{1}{5},\; B=-\frac{1}{5},\; C=\frac{3}{5}$$
$$\text{原式} = \frac{1}{5} \int \left( \frac{-x+3}{x^2-2x+2} + \frac{1}{x+1} \right) dx$$

**Step 2. 凑微分与配方**
$$(x^2-2x+2)' = 2x-2$$
$$-x+3 = -\frac{1}{2}(2x-2) + 2$$
$$\frac{-x+3}{x^2-2x+2} = -\frac{1}{2}\cdot\frac{2x-2}{x^2-2x+2} + \frac{2}{(x-1)^2+1}$$

**Step 3. 逐项积分**
$$\int \frac{-x+3}{x^2-2x+2} dx = -\frac{1}{2}\ln(x^2-2x+2) + 2\arctan(x-1)$$

**Step 4. 汇总结果**
$$\text{原式} = -\frac{1}{10}\ln(x^2-2x+2) + \frac{2}{5}\arctan(x-1) + \frac{1}{5}\ln|x+1| + C$$

### 例 2：$\int \frac{3x+6}{(x-1)^2(x^2+x+1)} dx$

**Step 1. 拆分**
$$\frac{3x+6}{(x-1)^2(x^2+x+1)} = \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{Cx+D}{x^2+x+1}$$

**Step 2. 系数方程**
$$3x+6 = A(x-1)(x^2+x+1) + B(x^2+x+1) + (Cx+D)(x-1)^2$$
$$\begin{cases} A + C = 0 \\ B - 2C + D = 0 \\ B + C - 2D = 3 \\ -A + B + D = 6 \end{cases} \implies \begin{cases} A = -2 \\ B = 3 \\ C = 2 \\ D = 1 \end{cases}$$

**Step 3. 逐项积分**
$$\text{原式} = \int \left( \frac{-2}{x-1} + \frac{3}{(x-1)^2} + \frac{2x+1}{x^2+x+1} \right) dx$$
$$= -2\ln|x-1| - \frac{3}{x-1} + \ln(x^2+x+1) + C$$
