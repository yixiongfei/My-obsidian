# 多项式除法

---

## 二、用 $x^3-y^3 \div (x-y)$ 举例

这里把 $x$ 当成"要除的对象"，$y$ 先当成一个普通数字（常数）看待——这一点很关键，不然容易懵。

被除式按 $x$ 的降幂排列，缺项补 0，方便对齐：
$$x^3+0x^2y+0xy^2-y^3$$

除式：$x-y$

### 第 1 步：最高次项消最高次项
被除式最高项 $x^3$，除式最高项 $x$：$x^3\div x=x^2$ → 商的第一项是 $x^2$

用 $x^2$ 乘回除式：$x^2(x-y)=x^3-x^2y$

拿被除式减掉它：
$$(x^3+0x^2y)-(x^3-x^2y)=x^2y$$

### 第 2 步：新余式继续消
新余式最高项 $x^2y$，$x^2y\div x=xy$ → 商加上 $xy$

$xy$ 乘回除式：$xy(x-y)=x^2y-xy^2$

减掉：
$$(x^2y+0xy^2)-(x^2y-xy^2)=xy^2$$

### 第 3 步：再消一次
新余式 $xy^2$，$xy^2\div x=y^2$ → 商加上 $y^2$

$y^2$ 乘回除式：$y^2(x-y)=xy^2-y^3$

减掉：
$$(xy^2-y^3)-(xy^2-y^3)=0$$

**余式为 0，除尽了！**

### 竖式全貌（对照小学除法的样子）

```
                x²  +  xy  +  y²          ← 商
        ┌─────────────────────────
 x - y  │ x³ + 0x²y + 0xy² - y³            ← 被除式
        │-(x³ -  x²y)                      ← x²×(x-y)，减掉
        └─────────────────────────
                x²y + 0xy²  - y³           ← 第一次余式
               -(x²y -  xy²)               ← xy×(x-y)，减掉
               └─────────────────────
                      xy²  - y³            ← 第二次余式
                     -(xy²  - y³)          ← y²×(x-y)，减掉
                     └─────────────────
                             0             ← 余式为 0，除尽
```

**结论**：
$$x^3-y^3=(x-y)(x^2+xy+y^2)$$

这就是我们在 [[伴随矩阵与可逆矩阵]] 里直接拿来用的立方差公式——它不是凭空背下来的，而是**多项式除法算出来的商**。

## 三、举一反三：$x^3+y^3\div(x+y)$

同样的套路，只是除式变成 $x+y$（可以看成 $x-(-y)$，把 $-y$ 当常数代入即可）：

```
                x²  -  xy  +  y²
        ┌─────────────────────────
 x + y  │ x³ + 0x²y + 0xy² + y³
        │-(x³ +  x²y)
        └─────────────────────────
               -x²y + 0xy²  + y³
              -(-x²y -  xy²)
              └─────────────────────
                      xy²  + y³
                     -(xy²  + y³)
                     └─────────────────
                             0
```

$$x^3+y^3=(x+y)(x^2-xy+y^2)$$

---

## 四、记这个方法的意义

以后遇到 $x^4-y^4$、$x^5-y^5$……不用死记一堆因式分解公式，**直接用这个竖式除法算一遍**就能推出商是什么。规律其实是：
$$x^n-y^n=(x-y)(x^{n-1}+x^{n-2}y+\cdots+xy^{n-2}+y^{n-1})$$
